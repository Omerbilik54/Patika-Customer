# Patika-Customer

🚀 Müşteri ve Sipariş Yönetim Sistemi

Java Swing ve MySQL kullanarak geliştirdiğim bu masaüstü uygulaması, küçük işletmelerin operasyonel süreçlerini dijitalleştirmeyi hedefleyen bir yönetim sistemidir.
🛠 Kullanılan Teknolojiler

    Dil: Java (Swing Arayüz)
    Veritabanı: MySQL
    Mimari: Katmanlı Mimari (Business-View-Entity)

✨ Temel Özellikler

    ✅ Müşteri Kaydı: Detaylı müşteri profili oluşturma ve yönetimi.
    ✅ Stok Takibi: Ürünlerin fiyat ve stok miktarlarının anlık kontrolü.
    ✅ Akıllı Sepet: Satış öncesi ürünleri sepete ekleme ve sepet yönetimi.
    ✅ Güvenli Giriş: Kullanıcı yönetimi ile sisteme yetkili erişim.

📂 Mimari Yapı

    View: Kullanıcı arayüzü (Swing)
    Business: İş mantığı ve veritabanı sorguları
    Entity: Veritabanı tablolarının Java sınıfları olarak karşılığı

🚀 Nasıl Çalıştırılır?

    Veritabanı dosyasını (SQL) MySQL üzerinde oluşturun.
    IDE'nizde projeyi açın ve veritabanı bağlantı ayarlarını yapılandırın.
    Uygulamayı çalıştırarak kullanmaya başlayın!
